# Repository structure

Every file and folder in the monorepo, and why it exists. Section numbers in
parentheses refer to `architecture_okapi.pdf`.

The layout is a **uv workspace**: `apps/` holds deployable services, `packages/`
holds shared libraries. Dependency direction is strictly downward — `apps` depend
on `packages`, never the reverse (§3).

---

## Root

| Path | What it is |
|------|------------|
| `pyproject.toml` | Workspace root. Declares members (`apps/api`, `packages/shared`), the shared dev-dependency group (pytest, ruff, black, mypy), and one canonical config block each for ruff, black, `mypy --strict`, and pytest so every package is linted and type-checked the same way. Not itself an installable package. |
| `uv.lock` | Single resolved lockfile for the whole workspace. Committed. Regenerated by `uv lock` / `uv sync`. |
| `.python-version` | Pins Python `3.12`. `uv` reads this and downloads the interpreter automatically. |
| `.pre-commit-config.yaml` | Git pre-commit hooks: `ruff` (lint + import sort, autofix), `black` (formatter), plus whitespace/EOF/YAML/TOML sanity checks. Black is the sole formatter; ruff-format is intentionally not enabled to avoid the two fighting. |
| `.env.example` | Template for local secrets/config. Copy to `.env` (git-ignored). All keys use the `OKAPI_` prefix and are loaded by `apps/api/.../core/config.py` (§6). |
| `Makefile` | Task shortcuts: `sync`, `run`, `test`, `lint`, `fmt`, `typecheck`, `check`, `migrate`, `revision`, `compose-up/down`, `opa-test`. Override the uv binary with `make run UV="python -m uv"` if uv isn't on `PATH`. |
| `.gitignore` | Ignores `.venv/`, `.env` (but not `.env.example`), build artefacts, and tool caches (`.ruff_cache`, `.mypy_cache`, `.pytest_cache`). |
| `README.md` | Project overview, layout summary, quickstart commands. |
| `STRUCTURE.md` | This file. |
| `architecture_okapi.pdf` | The source-of-truth design document. |

## `apps/api/` — the FastAPI service (`okapi-api`)

Implements all three layers from §2: Trusted Data Core, Verification & Compliance
Gate, AI Action Layer.

| Path | What it is |
|------|------------|
| `pyproject.toml` | Package metadata + runtime dependencies (FastAPI, uvicorn, SQLAlchemy, Alembic, psycopg, pgvector, httpx, pyjwt, passlib, anthropic) and `okapi-shared` via `[tool.uv.sources] … {workspace = true}`. Uses a `src/` layout with hatchling. |
| `alembic.ini` | Alembic config. `script_location`/`prepend_sys_path` use the `%(here)s` token so migrations resolve correctly no matter the working directory. DB URL is injected from settings in `env.py`, not stored here. |
| `README.md` | Layer-to-folder map and local-dev commands for this service. |

### `apps/api/src/okapi_api/`

| Path | What it is |
|------|------------|
| `__init__.py` | Package marker. |
| `main.py` | FastAPI app instantiation, router registration, `GET /health`. HTTP concerns only — no domain logic (§3, §12). |

#### `core/` — cross-cutting infrastructure

| Path | What it is |
|------|------------|
| `config.py` | `Settings` (pydantic-settings) loaded from env / `.env` with the `OKAPI_` prefix; `get_settings()` is `lru_cache`d. Dev-only defaults, no real secrets. |
| `security.py` | AuthN primitives only — JWT encode/decode and bcrypt password hashing. AuthZ is delegated to OPA (§6). |
| `logging.py` | `configure_logging()` — single JSON-line stdout handler (§8). |

#### `api/v1/` — HTTP routers

| Path | What it is |
|------|------------|
| `documents.py` | Router for `/documents`, `/documents/{id}/fields`, `/documents/{id}/query`, `PATCH …/fields/{field_id}`, `/documents/{id}/lineage` (§9). |
| `fields.py` | Router for field actions not nested under a document — `POST /fields/{field_id}/signoff`. |
| `forms.py` | Router for `/forms/{form_id}/autofill` and `/forms/{form_id}/submit` (§5.3). |
| `audit.py` | Router for `GET /audit` (read-only; the log is append-only, §4.1). |

Each router currently declares only its `APIRouter`; endpoint bodies stay ~5
lines when implemented — parse, call one service, return (§12).

#### `services/` — orchestration + domain logic

Unit-testable with mocked repositories/gate; services never touch a `Session` (§10).

| Path | What it is |
|------|------------|
| `retrieval_service.py` | Read flow: gate check → allowed field ids → RAG answer → per-field audit rows (§5.1). |
| `edit_service.py` | Write flow: gate → create version → hash-chain lineage edge → flag dependents; recorded as an amendment (§5.2). |
| `form_fill_service.py` | AI form auto-fill, gated per source field; drafts needing sign-off block submission (§5.3). |
| `extraction_service.py` | LLM-backed key-data extraction from unstructured text — the one model call on the write path (§3). |
| `versioning_service.py` | Appends `field_versions` rows with `value_hash` and array `parent_version_id` — the field-level versioning mechanism (§4.1). |
| `lineage_service.py` | Builds the DAG; computes `edge_hash = SHA256(parent_id + parent.value_hash + child.value_hash)` (§4.2). |
| `integrity_service.py` | Recomputes the Merkle root over a document's edges and compares to the stored root; detects out-of-band DB edits (§4.2, §5.1). |
| `propagation_service.py` | Walks `field_references`, sets `status='stale'` on dependents of an edited field (§4.5). |
| `rag_service.py` | pgvector similarity search restricted to allowed fields (§5.1). |

#### `gate/` — Layer 2, the single choke point

| Path | What it is |
|------|------------|
| `gate.py` | `Gate.check(policy_input)` — calls the policy client, raises `GateDenied` on deny before any repository query runs (§1 principle 1). Injected as a FastAPI dependency into every retrieving/mutating service method (§3). |
| `policy_client.py` | The only component that talks to OPA. POSTs `{input: …}` to `/v1/data/okapi/authz/result`, parses `{result: …}` into a `PolicyResult` (§6.1). |

#### `repositories/` — the only place SQL lives (§10)

| Path | What it is |
|------|------------|
| `document_repository.py` | CRUD for the `documents` container table. |
| `field_repository.py` | `fields`, `field_versions`, `lineage_edges`, `field_references`; home of the recursive-CTE DAG traversal (§4.3). |
| `audit_repository.py` | Append-only writes and filtered reads of `audit_log`. |

Each takes an `AsyncSession` in its constructor.

#### `models/`, `schemas/`, `db/`

| Path | What it is |
|------|------------|
| `models/__init__.py` | Re-exports `Base` so Alembic autogenerate sees all models. |
| `models/base.py` | SQLAlchemy `DeclarativeBase` subclass — shared metadata target. |
| `schemas/__init__.py` | Pydantic request/response bodies; re-exports `PolicyInput`/`PolicyResult` from `okapi_shared`. No raw dicts cross a layer boundary (§12). |
| `db/session.py` | Async engine + `async_sessionmaker`; `get_session()` dependency — the only place a `Session` is created. |
| `db/migrations/env.py` | Alembic environment. Pulls the DB URL from `get_settings()` (stripping the `+psycopg` async suffix) and metadata from `models.Base`. |
| `db/migrations/script.py.mako` | Template for generated migration files (typed, `ruff`/`black`-friendly). |
| `db/migrations/versions/.gitkeep` | Keeps the empty versions folder in git until the first migration. |

### `apps/api/tests/`

| Path | What it is |
|------|------------|
| `unit/test_health.py` | Smoke tests — `/health` and the OpenAPI schema load via `TestClient`. |
| `integration/README.md` | How to run end-to-end tests against real Postgres + OPA (`docker-compose.test.yml`). Target ≥80% coverage on `services/` and `gate/` (§10). |

## `packages/shared/` — `okapi-shared`

Types that cross layer boundaries. No I/O, no framework imports, so it's safe to
import from any layer or a future MCP tool surface.

| Path | What it is |
|------|------------|
| `pyproject.toml` | Package metadata; only depends on `pydantic`. |
| `src/okapi_shared/__init__.py` | Re-exports the public surface. |
| `src/okapi_shared/enums.py` | `ActorType`, `Decision`, `EdgeAction`, `ReferenceStatus` — mirror the DB ENUMs (§4.1). |
| `src/okapi_shared/contracts.py` | `GateActor`, `PolicyInput`, `PolicyResult` — the exact shapes exchanged with OPA (§6, §6.1). |
| `src/okapi_shared/constants.py` | `API_V1_PREFIX`, `HASH_ALGORITHM`, `OPA_DECISION_PATH`. |
| `tests/test_contracts.py` | Round-trip / defaults tests for the contract models. |

## `packages/policies/` — the OPA/Rego bundle

No Python. Mounted read-only into the OPA sidecar and evaluated over HTTP (§6, §6.1).

| Path | What it is |
|------|------------|
| `README.md` | File/package table and `opa test` / `opa fmt` commands. |
| `authz.rego` | `package okapi.authz`. Aggregate decision surface — `PolicyClient` reads `data.okapi.authz.result`. Combines RBAC + ABAC, deny-by-default. |
| `rbac.rego` | `package okapi.rbac`. Structural role checks. Deny-by-default skeleton. |
| `abac.rego` | `package okapi.abac`. Attribute checks keyed off `input.actor.attributes` (department, clearance_level, employment_type). Deny-by-default skeleton. |
| `compliance/hipaa.rego` | `package okapi.compliance.hipaa`. One file per compliance regime keeps them pluggable and centrally updatable (§6.1). |
| `compliance/dpdp.rego` | India DPDP regime. |
| `compliance/cdsco.rego` | CDSCO regime. |
| `tests/authz_test.rego` | `opa test` cases — asserts deny-by-default and the `result` shape. |

## `infra/` — deployment (prototype)

| Path | What it is |
|------|------------|
| `docker-compose.yml` | Three services on network `okapi_net`: `api` (uvicorn:8000), `opa` sidecar (:8181, policies bundle mounted), `db` (pgvector/pg16, :5432, named volume). Healthchecks; `api` waits on `db` and `opa` being healthy (§7). |
| `docker-compose.test.yml` | Ephemeral Postgres + OPA for integration tests — tmpfs data, non-default ports, no volumes. |
| `Dockerfile.api` | Multi-stage `uv` build of the `okapi-api` member. Build context is the repo root; copies workspace metadata first for layer caching, then source. Runtime stage is `python:3.12-slim` with the built `.venv`. |
| `opa/README.md` | How the sidecar loads `../packages/policies` and how to reload after editing a `.rego` file. |

## `scripts/` — dev helpers

| Path | What it is |
|------|------------|
| `bootstrap.sh` | `uv sync` + create `.env` from the example. One-time setup. |
| `migrate.sh` | Thin wrapper: `uv run --package okapi-api alembic -c apps/api/alembic.ini "$@"`. |
| `fmt.sh` | `ruff check --fix` then `black` over the whole workspace. |
| `seed.py` | Placeholder demo-data seeder — implement once models/repositories exist. |

## `.github/workflows/ci.yml`

Two jobs:

- **python** — `uv sync --frozen` → `ruff check` → `black --check` → `mypy` → `pytest`.
- **policies** — `opa fmt --list` → `opa test packages/policies`.

Both fail the build on any lint, type, or test error (§12).
